# Local's Quest

Discover curated regional quests, harvest festivals, orchards, and outdoor experiences across Halton, Peel, Durham, and Niagara.

## Features
- **Curated Discovery**: Explore seasonal local experiences categorized into Outdoors & Nature, Farm & Harvest, Wine & Cider, and Winter & Skating.
- **Interactive Leaflet Map**: Responsive geospatial view plotting exact quest addresses with custom SVG teardrop pins and preview cards.
- **Detailed Experience Sheets**: High-resolution photo carousel, uniqueness factors, family policies, member discounts, and direct check-in links.
- **Dynamic Filtering & Sorting**: Filter by maximum base admission and category, search across names and addresses, and sort by featured or price.

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Leaflet Maps
